# Mall Customers Unsupervised Clustering

## Project Description
This project focuses on identifying distinct customer segments within a mall's customer base using unsupervised machine learning techniques. By analyzing demographic data and purchasing behavior, the system aims to uncover hidden patterns that can inform targeted marketing strategies and personalized customer experiences. The project heavily relies on Python and the Pandas library for data manipulation and analysis[cite: 6].

## Key Features & Achievements
* **Data Ingestion and Exploration:** Utilized Pandas to successfully read and process the `Mall_Customers.csv` dataset, extracting key insights through functions like `head()`, `info()`, and `describe()`[cite: 6].
* **Demographic Analysis:** Processed a dataset of 200 mall customers, analyzing features including 'Gender', 'Age' (mean age 38.85), 'Annual Income (k$)' (mean income $60.56k), and 'Spending Score (1-100)'[cite: 6].
* **Data Profiling:** Conducted thorough data profiling to understand the distribution of customer attributes, identifying minimum, maximum, and quartile ranges for numerical features to inform the clustering algorithms[cite: 6].
* **Unsupervised Learning Preparation:** Structured and formatted the dataset to be primed for unsupervised clustering algorithms, laying the groundwork for K-Means or Hierarchical clustering implementations.
